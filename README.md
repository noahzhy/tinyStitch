# tinyStitch 合成数据网页

在浏览器内生成三维货架的有序拍摄图片。设置场景种子、货架长度、各子货架的层板数量和拍摄视角，逐张预览并下载。相同种子和参数可复现。

## 运行

需要 Node.js 22.18 或更新版本。

```sh
npm ci
npm run dev
```

开发网页：<http://127.0.0.1:5180>。

发布构建并在本机运行：

```sh
npm run build
npm start
```

网页：<http://127.0.0.1:8026>。不需要 Python、后端服务或模型权重。

## 数据生成

- 货架长度 1–12 模拟米，图片 2–48 张，支持固定值与随机范围。
- 子货架默认随总长度自动伸缩：目标每段 1 模拟米，数量向上取整后等宽分配；可调整目标宽度或手动设置数量，最多 24 段，每段独立设置 1–8 层层板（包含底层）。
- 输出 720×960 JPEG，默认采用仿真拍摄，偏航、俯仰各在 ±15° 范围连续随机扰动，并带轻微位置与采样时间变化；保留正面、左右斜拍和俯拍预设。
- 商品按同款连续多列、纵深多件陈列，包装一致；可设置空位概率、连续列数与纵深容量。
- 按商品实际宽度紧凑排列，间隙约 4 毫米；缺货时保留原货位，不收拢填空。
- 商品包含盒装、瓶装、罐装与广口罐，宽度随 SKU 变化，最大宽度保持原上限；瓶罐标签沿曲面贴合，RGB 和正交 GT 共用外形。
- 层间净空足够时，盒装、罐装与广口罐可从底部逐层堆叠；导出每件商品的堆叠层号、纵深位置与各货位容量，瓶装保持单层。
- 镜头距离随长度和图片张数调整，以维持拍摄范围覆盖。
- 可下载单张图片，或将整组图片与参数打包为 ZIP。
- 每组同时生成扫过区域的正面正交 GT，附覆盖掩码与坐标映射；未覆盖区域透明。覆盖按全部 RGB 视野在货架正面参考平面上的并集确定，不表示商品遮挡。
- ZIP 包含 `rgb/`、`gt/`、内参、时间戳、`capture.json`、`generation/scene.json` 与 CLI 可复用的 `generation/config.json`。
- `gt/camera_poses.json` 与 `.csv` 输出每张 RGB 渲染时相机真正的世界 6D 位姿（米 / 弧度 XYZ＋内禀 Euler XYZ），附四元数、原生与 OpenCV 双向变换矩阵；网页可查看当前帧并单独下载 JSON。
- 场景文件保存层板高度、逐帧视角与位姿，以及 SKU、货位（含空位）和每件商品的位置。固定路线间隔 0.5 秒，仿真拍摄间隔 0.45–0.55 秒。

生成和 ZIP 打包均在浏览器内完成。

## CLI 生成

CLI 需要本机 Chrome / Chromium，无需提前启动网页。完整操作、配置复用、批量生成和全部数据字段见 [CLI 生成文档](docs/CLI_GENERATION.md)。

```sh
npm run generate -- --out ./output/shelf-42 --seed 42 --length 6 --frames 12 --bay-mode auto --layers 3,4,5 --capture handheld --empty 0.25 --facings 2:5 --depth 3 --zip
```
